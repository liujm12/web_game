# TurboArcade Game Content Audit

Date: November 10, 2026  
Scope: all public game pages in `data/site-content.json`  
Purpose: identify the pages most likely to help or hurt the next AdSense review, then define a safe order for deeper content work.

## Executive summary

- The current codebase contains **23 live games**, not 22. Future inventory, sitemap, and review checklists should use 23 until a page is moved to draft.
- Every game is playable. The four games with an empty `componentKey` are local HTML5 embeds, not missing implementations.
- The main risk is **page-level sameness**, not technical indexability. Fourteen older game pages reuse the same mobile FAQ answer, and several reuse the same “best for” sentence.
- The strongest evidence of original value is currently on **Patrol Escape**, followed by the more complete logic games and games supported by a dedicated guide.
- Three pages should not remain public in their current form: **Orbit Hopper**, **Neon Drift**, and **Signal Sweep**. They substantially overlap stronger games, and Signal Sweep's strategy copy does not match its actual sequence-memory mechanic.
- One factual error must be corrected during the next content pass: **Sudoku Sprint uses 3x3 boxes, but two tips refer to 2x2 boxes**.

## Grading rules

### A — priority page

Keep indexed and strengthen first. The game has at least two of these qualities:

- a distinctive or complete implementation;
- meaningful original mechanics, generated content, or verified level design;
- a dedicated guide or enough first-hand detail to support one;
- a page that can credibly become a search landing page rather than only a play screen.

### B — keep, but rewrite

The game works and deserves to remain available, but the page is currently too short, generic, or unsupported by first-hand editorial detail. These pages should be improved only after the A pages form a convincing core.

### C — draft, merge, or fully rebuild

The game is playable but substantially duplicates another page, has content that does not match the mechanic, or adds too little unique value to justify a separate indexed URL. A C grade is not a judgment that the code is unusable; it means the public page weakens the site's overall content proposition in its current form.

## Site-wide evidence found during the audit

### Repeated editorial structure

- Most records contain exactly three instructions, three tips, three mistakes, and two FAQs.
- Fourteen pages use the exact question **“Does it work on phones?”** and the exact same answer.
- Seven pages use the exact sentence **“Anyone looking for an easy arcade break.”**
- Four pages use the exact sentence **“Anyone looking for an easy brain break.”**
- Repetition is amplified by the shared page layout, which renders the same sequence of sections for every game.

The shared component is not itself a policy problem. The risk is that the prose inside it looks produced from one template rather than written after playing each game.

### Guide coverage

Only four editorial guides currently support the full game catalog:

- 2048 Corner Strategy
- Snake: Build Space Before Length
- Breakout Paddle Control Guide
- Number Rush: Faster Clean Rounds

That is too little editorial support for 23 indexed game pages. The A pages should receive game-specific guides before more games are added.

### Accuracy problems

- Sudoku Sprint is a standard 9x9 game with 3x3 boxes, but two pieces of page advice incorrectly refer to 2x2 boxes.
- Signal Sweep's strategy and mistake copy describes a sweep/timing game, while the implementation is a Simon-style sequence-memory game.
- Several short tips are technically true but too generic to demonstrate first-hand testing, such as “Watch ahead,” “Survive first,” and “Avoid spamming.”

### Production crawl sample

A production crawl sample showed strong technical and crawlability scores, while the content category repeatedly produced warnings or failures. This supports treating the next phase as a content consolidation and originality project rather than another metadata-only SEO pass.

## Immediate actions after this audit

1. Move the three C pages to draft or remove them from the sitemap before the next review request.
2. Correct the Sudoku factual error and Signal Sweep mismatch before any page is kept public.
3. Build a reusable but flexible evidence section for A pages: “What we tested,” “How scoring works,” “What changes by difficulty,” and original screenshots.
4. Publish three new deep guides first: Patrol Escape, Sudoku Sprint, and Checkers Lite.
5. Replace repeated FAQ and “best for” copy only when a page has a genuinely game-specific answer; delete low-value sections rather than filling every template slot.
6. Reassess the B pages after the A cluster is complete. Do not add more games until this pass is finished.

Task 2 should begin only after confirming these two editorial decisions:

- **Primary lane runner:** keep Meteor Sprint; draft Orbit Hopper and Neon Drift.
- **Primary sequence-memory game:** keep Pattern Pulse; draft Signal Sweep unless it is rebuilt around a different mechanic.
